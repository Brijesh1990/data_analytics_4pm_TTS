# What is Protocol?

A protocol is a set of rules that computers and devices use to communicate over a network. Protocols define how data is formatted, transmitted, and received so different systems can understand each other.

## Types of Protocols

1. Network Protocols
   - TCP (Transmission Control Protocol)
   - IP (Internet Protocol)
   - UDP (User Datagram Protocol)
   - ICMP (Internet Control Message Protocol)

2. Internet Protocols
   - HTTP (Hypertext Transfer Protocol)
   - HTTPS (HTTP Secure)
   - FTP (File Transfer Protocol)
   - SMTP (Simple Mail Transfer Protocol)
   - POP3 (Post Office Protocol 3)
   - IMAP (Internet Message Access Protocol)

3. Security Protocols
   - SSL (Secure Sockets Layer)
   - TLS (Transport Layer Security)
   - SSH (Secure Shell)

4. Communication Protocols
   - DNS (Domain Name System)
   - DHCP (Dynamic Host Configuration Protocol)
   - ARP (Address Resolution Protocol)

5. Wireless Protocols
   - Bluetooth
   - Wi-Fi (IEEE 802.11)
   - NFC (Near Field Communication)

## Summary

Protocols ensure reliable and secure communication between devices on a network.
