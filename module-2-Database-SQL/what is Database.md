# What is a Database?

A database is an organized collection of related information stored in a computer system. It helps people and programs save, find, update, and manage data efficiently.

## Why databases are useful

- Store large amounts of information in one place
- Make it easy to search and retrieve data quickly
- Keep data accurate and consistent
- Allow multiple users or applications to share the same data
- Protect data with access controls and backups

## Common examples

- School systems storing(SMS) student names, grades, and attendance
- Bank systems storing (BSS) customer accounts and transactions
- Online stores storing products (eommerce), orders, and customer details
- Hospitals storing patient records and medical history

## Basic database structure

A simple database often uses:

- Tables: collections of related records (stored a structured data formate)
- Rows: individual records in a table 
- Columns: fields that describe each record

Example table: `students`

| id | name   | age | grade |
|----|--------|-----|-------|
| 1  | Anu    | 15  | 10    |
| 2  | Rahul  | 16  | 11    |

## Database vs DBMS

- A database is the data itself.
- A DBMS (Database Management System) is the software used to create, manage, and query the database.

Common DBMS examples: MySQL, PostgreSQL, Microsoft SQL Server, SQLite.

## Types of databases

- Relational database: stores data in tables with relationships (example: MySQL)

- NoSQL database: stores data in formats like documents or key-value pairs (example: MongoDB)

## Summary

A database keeps information organized so it can be used safely and quickly. It is one of the foundational tools for storing and working with data in computers.
